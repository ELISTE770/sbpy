# SBpy VS Code Extension

Integrates **SBpy** directly into Visual Studio Code via Language Server Protocol (LSP).

## Features
- ⚡ **Instant Error Diagnostics**: Underlines syntax errors, missing imports, and logic bugs in real-time.
- 💡 **Code Actions & Quick Fixes**: Click the lightbulb on errors to apply AI patches in 1-click.
- 🌐 **Web Dashboard Integration**: Open the SBpy project health dashboard with one command.

## Setup
1. Ensure SBpy is installed: `pip install -e .`
2. Run `sbpy setup` to configure your API keys.
3. Reload VS Code with the extension enabled.
